# ae-ffxdowngrader

Downgrade After Effects preset (.ffx) files down to ae 2022 easily, completely in terminal and only requires python3.

## How to use!

1. Install python3 if you don't already have it installed.
2. Download the ae-ffxdowngrader.py file from this repo.
3. Launch the file from terminal (python3 [location]).
4. Type the location of the ffx file or folder you want to convert to the first question (in terminal).
5. Then choose your target version for the 2nd question.

### To use for VKINTOX (SOBER ROBLOX LINUX SHADERS)
